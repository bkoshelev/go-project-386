# Triage Labels

Роли triage соответствуют следующим меткам GitHub Issues:

| Роль | Метка в трекере | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Задача ожидает первичной оценки |
| `needs-info` | `needs-info` | Требуется дополнительная информация от автора |
| `ready-for-agent` | `ready-for-agent` | Задача полностью описана и готова к реализации агентом |
| `ready-for-human` | `ready-for-human` | Требуется реализация человеком |
| `wontfix` | `wontfix` | Задача не будет выполнена |

Когда явно вызванный скилл упоминает роль triage, используйте соответствующую метку из таблицы.
Чтобы изменить названия меток, отредактируйте столбец «Метка в трекере».
