# Схема приложения бронирования

- `application.excalidraw` — редактируемый исходник схемы.
- Векторное и растровое превью не входят в комплект.

Статус: **HTTP-контракт и схема приняты пользователем**.
[Полная спецификация MVP](../../specs/booking.md) утверждена пользователем
19 октября 2026 года.

Откройте `application.excalidraw` в Excalidraw через «Открыть» или перетащите файл
в редактор. Текст, блоки и стрелки являются редактируемыми элементами.

Схема показывает frontend, backend и БД через пять потоков данных:

1. Профиль, просмотр и создание типов событий.
2. Недельное расписание, отдельные даты, первый часовой пояс владельца и общая пауза.
3. Получение свободных слотов и проверка введённого вручную начала без резервирования.
4. Атомарная проверка и создание бронирования; конфликт и повторная отправка.
5. Полный список текущих и будущих встреч владельца.

Сплошные стрелки обозначают запросы, чтение и запись. Пунктирные — возвращаемые
данные и результаты. Подписи содержат поля и модели принятого HTTP-контракта
из `api/main.tsp`; пояснения — в `specs/booking-api.md`.

Данные БД показаны логически. Названия блоков не фиксируют СУБД или физическую
схему таблиц. Блок транзакции обозначает требуемую атомарность проверки и записи,
не выбирая конкретный механизм блокировок.
