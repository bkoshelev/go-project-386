# ADR-0001: Самостоятельный фронтенд в frontend/

Статус: принято.

## Контекст

Нужно подготовить минимальную frontend-часть проекта. Бэкенда ещё нет;
пользователь указал, что он будет добавлен отдельной задачей. В интервью
обсуждались самостоятельный запуск из `frontend/` и единая команда из корня
с учётом будущего Go-бэкенда.

## Решение

Разместить фронтенд в `frontend/` и запускать его команды из этой папки.
На данном этапе не добавлять совместный запуск с Go, API-интеграцию или
инфраструктуру workspace.

Vite, Mantine и TypeScript — исходные ограничения пользователя. Сравнение
этих инструментов с альтернативами в интервью не проводилось.

## Последствия

- Фронтенд можно установить, запустить и проверить независимо от будущего бэкенда.
- Для этой задачи не нужно предполагать устройство Go-сервера и API.
- Совместный запуск и раздача фронтенда бэкендом потребуют отдельного решения
  при появлении соответствующей задачи.

## Почему решение сохранено

Это реальный выбор между независимым запуском и ранней интеграцией. Он объясняет,
почему в Go-проекте появляется самостоятельная frontend-папка без корневой команды.
