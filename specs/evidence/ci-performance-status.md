# Замеры ускорения CI

Пять заранее назначенных запусков дневной схемы прошли с первой попытки:
230, 197, 197, 186 и 214 с. Медиана — **197 с**, цель 216,7 с для базовой
дневной схемы достигнута. Исходные данные, SHA, job, timestamps и состояние
кэша инструментов сохранены в [ci-performance-baseline.json](ci-performance-baseline.json).
Первый запуск имел холодный кэш инструментов mise; остальные четыре фиксируют
попадания. Явный кэш модулей и сборки Go не использовался.

Отдельный [холодный запуск кандидата Go-кэша](ci-performance-cold-cache.json)
прошёл за 190 с с первой попытки; все четыре восстановления Go-кэша дали miss,
а кэш инструментов mise был прогрет. Это не прогретая серия и не основание
для расчёта или принятия выигрыша. Временный кандидат `9724270` отменён в
итоговой конфигурации до получения сопоставимых результатов.

Исторические 197,0 и 332 с относятся к другому составу проверок и не являются
сопоставимым измерением ускорения одинакового набора. Тесты с race,
govulncheck и production smoke теперь выполняются ночью и не включены в
дневное время; часть сокращения ожидания связана именно с изменением состава.

Приёмка всей спецификации не завершена: требуется сравнительная прогретая
серия Go-кэша, а также эксперимент двух shard при критической браузерной ветке.
Для прогрева по согласованной политике нужен запуск записи кэша на `main`;
пока новый workflow отсутствует в основной ветке, ручной запуск nightly через
GitHub также невозможен. Сравнение gain и окончательный выбор кэша и shard не
подтверждены. Данные, отсутствующие из-за отсутствия запуска, не считаются
успехом или нулевым временем.
