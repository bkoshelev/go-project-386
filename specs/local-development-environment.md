# Окружение локальной разработки и тестовые фикстуры

Статус: утверждено пользователем 20 октября 2026 года как основа реализации.
Реализовано и проверено 20 октября 2026 года.

## Согласованные решения

### Проверка testfixtures

В backend добавляется `github.com/go-testfixtures/testfixtures/v3` и YAML-набор
с одной записью существующей технической таблицы `example_records`.
Общий набор загружается один раз после миграций в тестовую PostgreSQL,
до запуска тестов. Ошибки подготовки завершают проверку неуспешно.

Отдельный интеграционный тест читает запись через sqlc и проверяет её значения.
Каждый обычный тест сохраняет существующую транзакцию с откатом.
Проверки генерации UUIDv7 и цикла миграций сохраняются.

### Окружение разработки

Решения об инструментах, env-файлах, setup и командах заменены
[спецификацией mise](mise-development-workflow.md) и [ADR-0018](../docs/adr/0018-mise-development-workflow.md).
Mise загружает необязательный `.env.local` текущего worktree. `mise run setup`
и bootstrap Orca подготавливают инструменты, зависимости, API-клиент, Chromium
и локальный `commit-msg`. `SETUP_VERIFY=1` дополнительно выполняет полный набор
проверок; значение по умолчанию — 0. Shell activation и direnv не требуются.
Go, Node.js и pnpm читаются из исходных языковых файлов; остальные версии — из
`mise.toml`, установки фиксируются штатным `mise.lock`.

## Критерии приёмки

1. `mise run backend:test` включает чтение YAML-фикстуры через sqlc,
   проверки UUIDv7, отката транзакций и миграций.
2. `mise run backend:test-unit` работает без Docker.
3. Подготовка окружения соответствует AC-01–AC-12 новой спецификации mise.

## История проверки

Первоначальная реализация фикстур и раздельного окружения mise/direnv проверена
20 октября 2026 на macOS amd64. Раздельное окружение заменено 7 ноября;
этот результат не является проверкой нового setup. Фикстуры и жизненный цикл
временных тестовых БД сохраняются. Dev-сервисы управляются отдельно через daemons.
